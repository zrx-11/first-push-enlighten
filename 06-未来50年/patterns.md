# 未来50年 模式与框架库

## 分析框架：预测拆解四步

1. 它属于趋势外推、情景设想还是价值判断？
2. 它的关键前提是什么（曲线、参数、机制）？
3. 哪个观测能推翻它？
4. 如果前提不成立，结论还剩什么？
四步能把“未来学”还原成可讨论的论证。

## 决策规则：看到指数曲线先找范式

if 有人在推演无限指数增长
  then 问：上一轮范式何时结束的？新范式靠什么？
  if 答不出
  then 这条曲线只是历史斜率，不是定律

## 反模式：把“读到”当“懂了”

测序、监测、成像都在降低“读”的成本，不降低“懂”的成本。把数据量当理解，是技术乐观论的常见漏洞。

## 反模式：把个体问题全推给个体

抑郁、教育、健康都受结构性因素影响。只讲“心态/努力”会遮蔽可改变的环境变量。
