# 逻辑的引擎 模式与框架库

## 分析框架：逻辑史的四次“地基危机”

1. 弗雷格：集合概括原则 → 罗素悖论；
2. 康托尔：无限与连续统 → 基数层级未定；
3. 希尔伯特：完备性要求 → 哥德尔否定；
4. 希尔伯特：可判定性要求 → 图灵否定。
每次危机的解法都不是“修补漏洞”，而是重新定义对象（类型论、公理化集合论、可计算性）。

## 决策规则：遇到“某系统能判定一切”的主张

if 主张者说系统能判定任意命题
  then 问：能否判定“本程序是否停机”
  if 能
  then 与停机问题矛盾，主张不成立

## 反模式：把行为相似当理解

ELIZA 式的对话幻觉：模式匹配能产生“被理解”的感受。判断时要看内部机制，而不是只看输出像不像。

## 反模式：把哥德尔定理当万能反驳

哥德尔只约束“足够强且一致的形式系统”。用它反驳具体计算模型时，必须说明该模型确实对应这样一个系统。
