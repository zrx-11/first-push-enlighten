# 数学的意义 模式与框架库

## 分析框架：立场定位四问

1. 数学对象存在吗？（实在论 / 反实在论）
2. 若存在，是独立的还是由实践确立？（柏拉图 / 简约）
3. 定理陈述对象还是结构？（对象语言 / 结构主义）
4. 客观性来自对象、程序还是规范？
四问能把任何一位作者放到坐标上。

## 决策规则：判断一个“数学是发明的”论证是否成立

if 论证只说“符号是人造的”
  then 追问：定义的后果由谁决定？
  if 后果由逻辑决定且不可预期
  then “发明”里已含“发现”，论证不完整

## 反模式：用哥德尔定理直接证柏拉图主义

哥德尔只谈给定系统的可证性，不承诺独立存在的对象世界。要用它，必须补上“真理独立于可证性”这一前提。

## 反模式：把“有效”当“真实”

数学在物理中有效，可能来自选择偏差或结构过度丰富。判断时要看是否有精确、可检验、非事后硬套的预言。
