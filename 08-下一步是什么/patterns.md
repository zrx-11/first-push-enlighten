# 下一步是什么 模式与框架库

## 分析框架：读一篇前沿短文的三问

①它说的“已知”是哪一层证据（神经/行为/统计）？②它推到的“未知”跨了几层？③跨层那一步有没有独立论证？三问能挡掉大部分过度解读。

## 决策规则：相关性还是因果

if 只有时间重合或空间重合
  then 先列替代解释（气候、采样偏差、共同原因）
  if 替代解释无法排除
  then 结论只能写“相关”

## 反模式：用脑区解释一切

“某区域激活”只说明任务与该区域有关，不说明该区域单独负责该功能。定位不等于解释。

## 反模式：把传播当证明

一个观念流传广、听起来顺，不等于有证据。二元论与“人脑只用 10%”都是传播优势的产物。
