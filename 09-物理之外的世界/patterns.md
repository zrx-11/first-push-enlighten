# 物理之外的世界 模式与框架库

## 分析框架：新事物出现的三层解释

①允许层：物理/化学是否允许？②组织层：是否有约束闭合维持它？③历史层：它是否在相邻可能之内？三层都过，才能说“可能出现”；缺一层，就只是想象。

## 决策规则：判断因果还是使能

if 从 A 能推出 B 的具体形式
  then 是 entailment
  else if A 出现后 B 有了可行路径，但形式不确定
  then 是 enablement
  写解释时不要混用两种句式。

## 反模式：把基因组当全部程序

序列只是线性代码层，折叠、膜、代谢、空间位置都不在序列里。把 DNA 当生命全图，会低估环境与组织。

## 反模式：把演化当目的论

“为了飞行长出羽毛”是倒果为因。演化只回应当前选择压，新功能是事后征用。
